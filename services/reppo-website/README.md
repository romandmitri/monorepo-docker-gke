# reppo-website

This is a root-level sample which will either host the corporate website and/or proxy to it.

---

## Commands

```
make reppo-website-local-logs
make reppo-website-local-restart
```

---

## Development

### Install

To install `node` packages:

* Update `package.json` file.
* Run `make reppo-api-local-install` command.
